# Discord Chat Sound

Мод для Minecraft на Fabric, который проигрывает звук при новых сообщениях в чате.

## Особенности
- Звук на системные сообщения (`/say`).
- Отключение своих сообщений (чтобы не слышать себя).
- Настройки через Mod Menu: вкл/выкл, ползунок громкости.
